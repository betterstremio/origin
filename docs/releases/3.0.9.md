The Mac beta is back in the release, posters fill faster on Windows and Macs, and update checks no longer fail when GitHub's hourly limit runs out.

**What’s new**

- Mac (beta) is built again for this release. It has everything from 3.0.3 to 3.0.8.
- On Windows and Macs, posters go up to the graphics card several at a time instead of about one per frame, so Home rows fill faster.
- Update checks read a small file on the Origin website before asking GitHub. GitHub allows 60 checks an hour from one home network without an account, and when they ran out Settings > About said "Could not check for updates". This applies to Windows, Android, Mac and Samsung from 3.0.9 on. Versions before 3.0.9 still ask GitHub, so if one says it could not check, try again an hour later.

**Opening the Mac app the first time**

Origin is not signed with an Apple Developer ID. Drag it to Applications, then run this in Terminal before you open it:

```
xattr -dr com.apple.quarantine /Applications/Origin.app
```

On macOS 26, Open Anyway in System Settings can leave Origin bouncing in the Dock with no window. If that happened, force quit it (Option-Command-Esc), run the command, and open it again. Run the command again after each update.

**Which file to download**

- LG webOS uses `io.github.betterstremio.origin_3.0.9_arm.ipk` or the Homebrew Channel.
- Android TV, Google TV and most TV boxes use `io.github.betterstremio.origin_3.0.9_android-arm64.apk`.
- Fire TV sticks and older boxes use `io.github.betterstremio.origin_3.0.9_android-armv7.apk`. The `_android.apk` includes both CPU types.
- Android phones and tablets use `io.github.betterstremio.origin_3.0.9_android-phone-beta.apk`.
- Windows uses `io.github.betterstremio.origin_3.0.9_windows_setup.exe` or the portable zip.
- Macs with Apple Silicon (beta) use `io.github.betterstremio.origin_3.0.9_macos-arm64.dmg`.
- Samsung TVs (preview) use `io.github.betterstremio.origin_3.0.9_tizen-beta.tpk`.
