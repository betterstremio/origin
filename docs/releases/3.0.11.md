A fix for pointing and clicking in the player.

**Fixed**

- With the LG Magic Remote or a mouse, clicking the name of Subtitles, Audio or Sources in the player's row of buttons paused the film instead of opening the menu. Pointing at one of these buttons opens it to show its name, and the name moves under the pointer, but only the icon took the click. Now the whole button does (#34, reported by @grubiroza with the fix).

**Mac**

The Mac app stays on 3.0.9 for this release.

**Which file to download**

- LG webOS uses `io.github.betterstremio.origin_3.0.11_arm.ipk` or the Homebrew Channel.
- Android TV, Google TV and most TV boxes use `io.github.betterstremio.origin_3.0.11_android-arm64.apk`.
- Fire TV sticks and older boxes use `io.github.betterstremio.origin_3.0.11_android-armv7.apk`. The `_android.apk` includes both CPU types.
- Android phones and tablets use `io.github.betterstremio.origin_3.0.11_android-phone-beta.apk`.
- Windows uses `io.github.betterstremio.origin_3.0.11_windows_setup.exe` or the portable zip.
- Samsung TVs (preview) use `io.github.betterstremio.origin_3.0.11_tizen-beta.tpk`.
