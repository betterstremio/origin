**Home**
- The next few cards in the row you are scrolling load their open-card picture, sharp picture and logo first, so each title is ready when it reaches the open card. On an LG C1, all 11 titles in a walk along a row were ready on arrival.
- A picture that is already loaded shows at once. Only one that arrives late fades in.
- Cards further along the row still start with the quick small picture, so rows fill as fast as in 2.1.10.
