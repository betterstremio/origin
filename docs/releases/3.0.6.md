Stream lists can show results sooner when many add-ons are installed. Slow add-ons spend less time holding up requests to faster ones, and the stream list and player’s Sources menu now support up to 128 add-ons. [Issue #18](https://github.com/betterstremio/origin/issues/18)

**Which file to download**

- Android phones and tablets use `io.github.betterstremio.origin_3.0.6_android-phone-beta.apk`.
- Android TV, Google TV and most TV boxes use `io.github.betterstremio.origin_3.0.6_android-arm64.apk`.
- Fire TV sticks and older boxes use `io.github.betterstremio.origin_3.0.6_android-armv7.apk`. The `_android.apk` includes both CPU types.
- LG webOS uses `io.github.betterstremio.origin_3.0.6_arm.ipk`.
- Windows uses `io.github.betterstremio.origin_3.0.6_windows_setup.exe` or the portable zip.
- Samsung TVs (preview) use `io.github.betterstremio.origin_3.0.6_tizen-beta.tpk`.
- The Mac beta is available from the [3.0.2 release](https://github.com/betterstremio/origin/releases/tag/v3.0.2).
