Origin now runs on Windows, and the TV apps get a new start screen and an easier way to turn on For You.

**Windows (new)**
- For Windows 10 and 11, 64-bit. Take the setup (installs for your user, no administrator prompt) or the portable zip
- Mouse and keyboard: click to open, right click to go back, type on Home to search, F11 or the button at the top right for fullscreen
- Video plays through mpv with hardware decoding, HDR and Dolby Vision tone-mapped to your screen
- 5.1 and 7.1 sound is folded down to stereo for headphones without clipping
- Streams that drop reconnect where they left off
- Updates install from Settings > About, and the app opens again when done
- The files are not code-signed: SmartScreen says the publisher is unknown (More info, then Run anyway). Each one was scanned with Microsoft Defender before it was published, and the setup has a .sha256 file to check it against

**Every platform**
- A new logo and start screen. It is silent for now
- For You: if your Nuvio account has a TMDB key saved, the app uses it, so recommendations start with no typing. Settings > For You also has a TMDB key row
- What's new and Settings no longer list things a device can't do
- The first-start tour leaves out the remote pages on Android and Windows

**Android**
- Smaller downloads: one APK per CPU type. Take `_android-arm64.apk` for most devices, `_android-armv7.apk` for Fire TV sticks and older boxes. The `_android.apk` with both still works
