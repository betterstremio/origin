A clearer way to add your TMDB key, and more control over For You.

**TMDB key**
- Settings > Keys has a TMDB key row that says which key is in use: the one from your Nuvio account, your own, or none
- If the app is using your Nuvio account's key, you can keep it, stop using it, or add your own instead. You can switch back to the Nuvio key at any time
- A key you remove stays removed. The Nuvio key no longer comes back on its own after the next sync
- Windows: no more QR code. Copy your key, then press Paste key, Enter or Ctrl+V. The card links to themoviedb.org if you don't have a key yet, and tells you if TMDB turned the key down

**For You**
- Pick a main language and a second one in Settings > For You. Rows in those languages show up more often, without hiding the rest. Automatic works as before
- New setting, Card opens after: how long the cinematic Home waits before a card opens. The default is now 0.25 s (it was 0.12 s). Set it to At once for the old timing
