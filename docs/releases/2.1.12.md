Torrents no longer crash the app partway through a film, and this version gets you ready for the move to a new app id.

**Which file to download**
- Android phones and tablets: `tv.stremioorigin.app_2.1.12_android-phone-beta.apk`
- Android TV, Google TV and most TV boxes: `tv.stremioorigin.app_2.1.12_android-arm64.apk`
- Fire TV sticks and older boxes: `tv.stremioorigin.app_2.1.12_android-armv7.apk` (`_android.apk` holds both CPU types)
- LG webOS: `tv.stremioorigin.app_2.1.12_arm.ipk`
- Windows: `tv.stremioorigin.app_2.1.12_windows_setup.exe`, or the portable zip

**Torrents (#15)**
- Playing a torrent could close the app after a few minutes, with "free(): invalid next size" or "malloc(): memory corruption" in the log. It happened when other people in the swarm were downloading from you while the app cleared old parts of the film from storage. The torrent library then wrote past the end of a list and broke the app's memory.
- The fix is upstream's patch for the same bug. On an LG C1 the old engine crashed within a minute under that load; the new one kept going.
- On webOS the torrent engine is now built from this project's own source instead of being copied from Stremio Origin 1.0.0.
- Android had the same bug and gets the same fix. Windows had the faulty code too, though it did not crash there.

**Sound**
- When none of a film's audio tracks is in your language, a DTS or TrueHD track in the film's original language is converted and played, instead of switching to a dub. A track in your language still plays at once.
- The message names DTS or TrueHD correctly.

**A new app id is coming**
- Origin has shared its app id, `tv.stremioorigin.app`, with Stremio Origin, so installing one replaced the other. The next version installs as a separate app, `io.github.betterstremio.origin`, and both can then sit on the same TV.
- 2.1.12 is the last version under the old id. When the next one is out, the update in Settings > About installs the new app beside this one and opens it. On Android you confirm the install once.
